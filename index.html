使い方

このツールについて

「同時視聴アシスト」は、永井浩二チャンネルの Twitch・YouTube 同時配信を、1 画面でまとめて見るためのツールです。 配信映像と、Twitch・YouTube 両方のコメント欄を並べて表示します。好きなページや別のウィンドウを映せる「EX枠」も使えます。

基本の使い方

  1. Twitch にチャンネル名を入れます（最初から nagaikouji074 が入っています）。
  2. YouTube に配信ページの URL を貼ります。
    例: https://www.youtube.com/watch?v=…、https://youtu.be/…
    YouTube の URL は配信ごとに変わります。チャンネルの URL（youtube.com/@…/live など）では配信を特定できないので、配信ページを開いてその URL を貼ってください。
  3. Enter を押すと反映されます（入力欄から離れても反映されます）。

画面の切り替え

  • 「Twitch映像」「YouTube映像」のボタンで、どちらの映像を出すか切り替えます。表示中の方をもう一度押すと映像を隠します。片方しか入力していないときは、入力した方の映像を出します。
  • 「EX枠」「Twitchコメント」「YouTubeコメント」のボタンで、それぞれ表示・非表示を切り替えます。
  • 枠の間の線をドラッグすると、幅や高さを変えられます。
  • ▲ で上のバーを隠し、右上の ▼ で戻します。EX枠の入力欄やボタンも一緒に隠れます。
  • 設定（チャンネル名・表示状態・枠の大きさなど）はこのブラウザに保存されます。YouTube の URL は配信ごとに変わるので保存しません。

EX枠

映像の下に、好きなものを表示できる枠です。実況しながらの同時視聴などにどうぞ。 上のバーの「EX枠」ボタンで表示します。 メインの映像を隠すと（表示中の映像ボタンをもう一度押す）、EX枠が縦いっぱいに広がります。

URL を表示する

  • EX枠の入力欄に URL を入れて Enter を押します（入力欄から離れても反映されます）。
  • YouTube の動画 URL や、Twitch のチャンネル・アーカイブ・クリップの URL は、普段の URL をそのまま貼れば表示できます。
  • それ以外のページは、埋め込みを許可しているものだけ表示できます。真っ白になる・エラーが出る場合は、下の「ミラー」を使ってください。

ミラー（別のタブ・ウィンドウを映す。埋め込みが禁止されている中継などに）

  1. 見たい中継を、別のタブかウィンドウで開いておきます。
  2. EX枠の「ミラー」を押し、出てきた画面で中継のタブかウィンドウを選んで「共有」を押します。
  3. EX枠に映ります。元のウィンドウが後ろに隠れても映り続けます。
  • 映っているのは映像だけです。一時停止や音量などの操作は、元のタブ・ウィンドウで行ってください。音も元のタブから出ます。
  • 映している間は、「全体を収める」「枠いっぱい」（端が切れる代わりに余白なし）で映し方を切り替えられます。
  • 元のウィンドウを最小化すると映像が止まります。
  • 映像はこのパソコンの中で表示しているだけで、どこにも送信されません。
  • 止めるときは「停止」か、ブラウザの「共有を停止」を押します。EX枠を隠したときも止まります。
  • パソコンの Chrome・Edge・Firefox で使えます（スマホでは使えません）。

小技: 映像を最前面に浮かせる

Chrome・Edge では、動画の上で右クリックを 2 回するとブラウザのメニューが出て、「ピクチャー イン ピクチャー」で映像を小窓にして最前面に浮かせられます。 YouTube のプレイヤーにある小窓ボタンでも同じことができます。

よくある質問

  • コメントを書き込めない
    ブラウザの設定によって、埋め込みのコメント欄がログイン状態にならないことがあります。書き込むときは Twitch・YouTube の公式ページからお願いします。
  • YouTube のコメントが出ない
    URL が今の配信のものか確認してください。配信終了後や配信の設定によっては表示されないことがあります。
  • EX枠の動画に「埋め込みが無効です」と出る
    配信元が埋め込みを禁止しています。「ミラー」を使ってください。
  • スマホで見たい
    縦に並べて表示します。「ミラー」はスマホでは使えません。

ご注意

  • Twitch・YouTube とは関係のない非公式ツールです。両サービス公式の埋め込みを並べて表示しているだけです。
  • このツールはコメントや個人情報を集めていません。設定はお使いのブラウザの中にだけ保存されます。
